# 5월 25일 호우 대응 보도자료 검색 — 제출 안내

## 포함 파일
- index.html: 모바일 대응 정적 페이지. JSON을 fetch로 읽고 부처·본문 키워드 검색, 부처 선택, 결과 N건 표시, 본문 펼치기, 첫 문단 발췌 요약 제공.
- 보도자료데이터.json: 첨부 데이터 3건. 배포용으로 바깥쪽 Markdown 코드 펜스만 제거하고 필드 값은 보존.
- solution.py: 표준 라이브러리만 사용하는 CSV 추출기.
- 결과_1,820.csv: 실행 검증 예시(2건).

## Python 실행
Python 3에서 solution.py와 보도자료데이터.json을 같은 폴더에 둡니다.

```sh
python solution.py "1,820"
```

예상 출력:
```
[OK] 2건 저장 → 결과_1,820.csv
```

명령어는 pytyon이 아니라 python입니다. Windows에서는 설치 방식에 따라 `py solution.py "1,820"`도 가능합니다.

- 정확히 인자 1개를 입력합니다. 공백이 있으면 따옴표로 감싸세요.
- 본문에 검색어가 문자 그대로 포함된 자료만 추출합니다. 제목·부처 필드는 검색하지 않습니다.
- 출력 위치는 스크립트 폴더입니다. 같은 검색어로 실행하면 기존 CSV를 덮어씁니다.
- UTF-8 BOM(utf-8-sig), 헤더 순서: 번호, 부처, 제목, 본문. 일치 자료가 없어도 헤더만 있는 CSV가 생성됩니다.
- 파일명으로 쓸 수 없는 문자(< > : " / 역슬래시 | ? *)와 제어문자가 포함된 키워드는 오류로 안내합니다.
- 첨부 원본 JSON처럼 ```json 코드 블록으로 감싼 파일도 지원합니다.

## 무료 배포 — GitHub Pages
이 문서와 ZIP은 배포 준비 산출물이며, 실제 호스팅 업로드나 공개 URL 발급은 완료하지 않았습니다.

1. 본인 GitHub 계정에서 공개 저장소를 생성합니다. 공개를 허용한 가상 자료만 업로드하세요.
2. 저장소 최상위에 `index.html`, `보도자료데이터.json` 두 파일을 업로드하고 커밋합니다. ZIP 자체를 올리는 것이 아니라 압축을 풀어 두 파일을 올립니다.
3. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch를 main, 폴더를 /(root)로 지정하고 저장합니다.
5. 배포가 끝나면 Pages 화면에 표시되는 실제 사이트 주소를 엽니다. 저장소 주소가 아니라 사이트 주소를 제출하세요.

제출 URL: Pages가 발급한 실제 URL을 기입할 것. 이 패키지는 임의의 공개 URL을 만들어 기재하지 않습니다.

호스팅의 무료 제공 조건과 화면 구성은 서비스 정책에 따라 달라질 수 있습니다.

## 배포 후 수동 점검
- 최초 접속: 결과 3건 / 부처별 카드 3개.
- 1,820 입력: 결과 2건(행정안전부·기상청).
- 1,800 입력: 결과 1건(경찰청).
- 기상청 입력: 결과 1건.
- 부처 드롭다운 경찰청: 결과 1건. 검색어와는 AND 조건.
- 없는 검색어: 결과 0건 및 안내 문구.
- 초기화: 전체 3건 복원.
- 본문 펼치기: 해당 보도자료 전체 본문 표시. Markdown 제목·강조·구분선만 읽기용으로 정리.
- 외부 우산 이미지가 실제로 표시되는지 확인(인터넷 연결 필요).
- 모바일 화면, 키보드 탭 이동 확인.

## 자료 해석과 검증 범위
원문은 가상 자료입니다. 페이지도 공식 정부 사이트가 아닌 과제용 시안으로 명시했습니다. 비교표는 원문을 수동 대조해 작성했으므로 JSON을 바꾸면 표도 함께 수정해야 합니다. 요약은 첫 문단을 그대로 발췌하며 새로운 수치나 판단을 생성하지 않습니다.
인력·예산·시각·지역·피해 수치가 달라도 적용 범위와 시점이 다를 수 있어 오류나 확정값으로 단정하지 않았습니다.
실행 검증은 Python CLI 및 CSV 읽기 검증 기준입니다. 실제 브라우저 표시와 공개 호스팅 접속은 배포 후 위 목록으로 확인하세요.
